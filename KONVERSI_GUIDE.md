# Panduan Konversi: PHP Native → Laravel

## 📋 Ringkasan Konversi

Proyek Valora telah berhasil dikonversi dari PHP Native MVC menjadi Laravel Framework dengan mempertahankan tampilan dan logika bisnis yang sama.

## ✅ Yang Sudah Dikonversi

### Struktur Framework
- ✅ Routing: `routes/web.php` (mengganti `router.php` dan `App.php`)
- ✅ Controllers: Semua controller dikonversi ke `app/Http/Controllers/`
- ✅ Middleware: Membuat middleware stack Laravel
- ✅ Configuration: Setup `.env`, config files
- ✅ Service Providers: Siap untuk dependency injection

## 🚀 Cara Menjalankan

### 1. Install Dependencies
```bash
composer install
```

### 2. Setup Environment
```bash
cp .env.example .env
```

Edit `.env` dan pastikan database credentials sudah benar:
```
DB_HOST=sq-7tm.h.filess.io
DB_PORT=61002
DB_DATABASE=pemweb_properlyby
DB_USERNAME=pemweb_properlyby
DB_PASSWORD=94da42107be4051036514940cf31d63f1b52dc13
```

### 3. Generate Application Key
```bash
php artisan key:generate
```

### 4. Jalankan Development Server

**Opsi A: Menggunakan Artisan (Recommended)**
```bash
php artisan serve
```
Aplikasi akan berjalan di `http://localhost:8000`

**Opsi B: Menggunakan PHP Built-in Server**
```bash
php -S localhost:8000 -t public
```

**Opsi C: Menggunakan Apache/Nginx**
- Pastikan DocumentRoot menunjuk ke folder `public/`
- Laravel akan otomatis handle routing via `.htaccess`

## 🔄 Kompatibilitas Kode Lama

### Base Controller Method
Controllers masih bisa menggunakan method lama:
```php
// Ini masih berfungsi
$this->view('templates/header', $data);
$this->model('AkunModel');
```

Karena base Controller di `app/Http/Controllers/Controller.php` menyediakan method compatibility layer.

### Database Connection
- PDO connection tetap sama
- Database credentials dari `.env`
- Models bisa tetap menggunakan raw queries

### Session Management
- `$_SESSION` tetap berfungsi normal
- Dikonfigurasi di `config/session.php`

## 🔧 Perbedaan Utama Dari Native PHP

| Aspek | Native PHP | Laravel |
|-------|-----------|---------|
| Routing | `router.php` + `App.php` | `routes/web.php` |
| Entry Point | `public/index.php` | `public/index.php` (updated) |
| Config | `config/config.php` | `.env` + `config/` folder |
| Controllers | `app/Controllers/` | `app/Http/Controllers/` |
| Namespace | Tidak ada | PSR-4 namespace |
| Middleware | Manual di controller | Middleware stack di Kernel |
| Requests | `$_GET, $_POST, $_FILES` | `Request` object (optional) |

## 🐛 Troubleshooting

### Error: "Class not found"
- Pastikan `composer install` sudah dijalankan
- Clear autoloader cache: `composer dump-autoload`

### Error: "View not found"
- Pastikan views di folder `views/`
- View paths menggunakan dot notation: `view('templates.header')`

### Error: "Storage permission denied"
- Buat folder: `mkdir storage/framework/cache`
- Set permissions: `chmod -R 775 storage/`

### Database connection error
- Check `.env` credentials
- Pastikan database server berjalan
- Test connection: `php artisan tinker` → `DB::connection()->getPdo()`
